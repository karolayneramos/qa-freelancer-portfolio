# Relatório Final de QA

## 1. Objetivo

Documentar os resultados dos ciclos de testes manuais realizados em um aplicativo de gestão de tarefas, com foco na identificação de defeitos e oportunidades de melhoria.

## 2. Resumo dos resultados

O projeto contou com 8 ciclos de teste e registrou 97 ocorrências:

|   | Tipo de ocorrência         | Quantidade |
| - | -------------------------- | ---------: |
|   | Bugs                       |         88 |
|   | Funcionalidades (features) |          3 |
|   | Melhorias                  |          6 |
|   | **Total**                  |     **97** |

Conforme o relatório final, todas as 97 ocorrências foram resolvidas, correspondendo a uma taxa de resolução de 100%.

## 3. Principais atividades

- Execução de testes manuais.
- Identificação e registro de comportamentos inesperados.
- Documentação de defeitos e melhorias.
- Acompanhamento dos resultados dos ciclos de teste.

## 4. Aprendizados

A experiência contribuiu para o desenvolvimento de habilidades de observação, investigação de problemas e documentação de resultados, além de reforçar a importância dos testes para a qualidade do software.

## 5. Confidencialidade

O nome do cliente, os dados de acesso e as informações internas do sistema foram omitidos desta versão pública.
